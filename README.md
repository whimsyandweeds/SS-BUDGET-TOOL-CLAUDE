# SS BUDGET TOOL CLAUDE

Sophie + Sage 30/60/90-day survival budget. A calm planner for estimating move-in and monthly costs when leaving without a shelter stay.

Nothing entered in the tool is saved or shared. Quick Exit clears the page and opens a neutral site.

## What this is

This is the Claude artifact version of the Sophie + Sage budget tool. Cost estimates and the resource list are generated in-session with Claude’s `sample` helper (`claude.use('sample')`). That helper only exists inside a Claude artifact, so opening this file on GitHub Pages will show the form but will not return local estimates.

The earlier standalone repo is still at [Sophie-Sage-Budget-Tool](https://github.com/whimsyandweeds/Sophie-Sage-Budget-Tool).

## Files

- `index.html` — the budget tool
- `.nojekyll` — so GitHub Pages serves the page as-is if Pages is turned on
